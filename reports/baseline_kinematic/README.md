동역학 전환 직전의 운동학 모드 결과입니다. 2~4단계의 비교 대상이며,
`--mode kinematic`으로 재현되어야 하는 값입니다.

## 모델 상태

P0(충돌 메쉬 면 누락) **복구 이후**입니다. 전 소스 OBJ 로드율 100%.
지문은 `metrics.json`의 `model_fingerprint`에 있습니다.

| 로봇 질량 | 142.1136 kg |
| 로봇 충돌 geom | 47개 (P0 복구 전 32개) |
| 환경 충돌 geom | 3개 (floor, pallet, conveyor) |

## 재현

```bash
MUJOCO_GL=egl OPENBLAS_NUM_THREADS=1 python run.py --boxes 32 --selection ordered
MUJOCO_GL=egl OPENBLAS_NUM_THREADS=1 python run.py --boxes 32 --seed 7
MUJOCO_GL=egl OPENBLAS_NUM_THREADS=1 python run.py --boxes 28 --seed 2
MUJOCO_GL=egl OPENBLAS_NUM_THREADS=1 python run.py --boxes 32 --seed 2   # FAIL 재현
```

모델을 다시 만들어야 하면 `python scripts/prepare_robot.py`를 먼저 돌립니다.
모델 무결성은 `python scripts/step1_check.py`로 확인합니다.

## 1단계(조향) 수정 이후 대조

이 기준선은 조향 수정 **이전**에 동결됐습니다. 수정 후 동결된 32개 실행 3건을 모두
다시 돌려 대조한 결과입니다.

| 지표 | `ordered` | `seed 7` | `seed 2` |
|---|---|---|---|
| 적재 / 구역별 | 32/32 [8,8,8,8] → **동일** | 32/32 [8,8,8,8] → **동일** | 30/32 [8,7,8,7] → **동일** |
| 판정 | PASS → PASS | PASS → PASS | FAIL → **FAIL (동일 지점)** |
| 이벤트 수·순서 | 322 → **동일** | 322 → **동일** | 309 → **동일** |
| 시뮬레이션 시간 | 1341.625 → 1341.625 s | 1341.785 → 1341.750 s | 1295.635 → 1295.365 s |
| 최대 관절 속도 사용률 | 0.8367084 → 0.8367084 | 0.8507450 → 0.8527312 | 0.8684153 → 0.8674891 |
| 최대 IK 성분 오차 | 2.9372342e-4 → 2.9372335e-4 | 2.9370300e-4 → 2.9370300e-4 | 2.9372519e-4 → 2.9372519e-4 |
| 최대 스택 드리프트 | 14.70 → 11.14 mm | 13.60 → 16.77 mm | — (중단 전) |

**이벤트 순서는 세 실행 모두 완전히 동일합니다.** 슬롯 선택, 적재 순서, 실패 지점이
전부 보존됐습니다. `seed 2`는 같은 자리에서 같은 방식으로 실패합니다 — 알려진 미해결
건이 조향과 무관함이 확인됐습니다.

### 달라진 것과 그 이유

시간은 최대 270 ms(0.02%), 속도 사용률은 0.23% 안에서 움직입니다. `ordered`는 완전히
동일하고 random 선택 실행만 흔들립니다.

원인은 **IK 해의 13번째 자리**입니다. `ik_seed()`가 전체 `qpos`를 넘기므로 IK의 충돌
회피 브로드페이즈가 조향된 바퀴 geom을 보고, 해가 1e-16 수준에서 달라집니다. 이 잔차가
`track()`의 `math.ceil(dt / timestep)` 경계를 몇 군데에서 넘기면서 스텝 수가 한두 개
바뀌고, 토트 적층 접촉에서 증폭됩니다. 시뮬레이터 자체는 비트 단위로 결정적입니다
(같은 코드·seed로 2회 실행 → 토트 위치 차이 0.000000 mm). 8박스 대조에서는 이벤트
시점 차이가 **0**인데도 토트 위치가 0.94 mm 다른 것으로, 경로가 아니라 수치 잔차가
원인임을 분리해 확인했습니다.

**스택 드리프트는 이 잡음에 지배됩니다** — `ordered`는 −24%, `seed 7`은 +23%로 방향이
갈립니다. 개선도 악화도 아니고 ±3 mm 정착 잡음으로 읽어야 합니다. 토트 최종 좌표도
같은 이유로 비교 대상이 아닙니다(최대 13.06 mm 차이).

따라서 **동역학이 재현해야 할 수치는 사이클 타임·속도 사용률·IK 오차·베이스 변위이고,
위 표의 범위 안에서 유효합니다.** 드리프트는 3단계(실제 접촉) 이후에 다시 정의해야
합니다.
