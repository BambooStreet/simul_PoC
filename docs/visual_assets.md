# 토트·팔레트 외형 개선

## 참고 근거

- 사용자 제공 사진의 외형 치수: 토트 500×400 mm, 팔레트 1200×1000 mm.
- 사용자 현장 수치(이번 요청): 토트 높이 **252 mm**, 팔레트 높이 **123 mm**, 중첩 1개당 **+58 mm**. 이전 250/150 mm 값을 대체한다.
- 엔드이펙터 사진 5장: 손목 체결 플레이트(볼트 원형 패턴), 아래로 테이퍼지는 아암, 끝단 돌기. 손잡이 구멍 삽입용이며 실측 치수는 없다.
- [아시아경제 김포 물류센터 현장 사진 (2021-03-30)](https://view.asiae.co.kr/en/article/2021033012082470807): 청보라색 개방형 토트, 노란 상단 바, 상단 보강 테두리와 측면 성형 형상을 관찰해 모델링.
- 팔레트는 사용자 사진에 보이는 녹색 격자형 제품을 참고. KPP N12 / AJ 12A의 제조사 도면을 확보한 것은 아니므로 특정 금형의 정확한 복제품은 아니다.

## 적용 내용

- 아래로 좁아지는 불투명 토트 몸체, 둥근 모서리, 실제 열린 내부 및 양 끝 손잡이 구멍.
- 이중 보강 테두리, 연속된 측면 보강 리브, 노란색 상단 바와 힌지 형태, 식별 라벨.
- 녹색 팔레트의 격자 상판, 하부 러너 3개, 지지 블록 9개, 포크 진입용 개구부.
- 토트 외형 X=400/Y=500/Z=**252** mm, 팔레트 X=1000/Y=1200/Z=**123** mm. 기존 좌표와 방향 유지.
- 손잡이 구멍을 토트 상단에서 중첩 pitch 이내(중심 기준 z=78–118 mm)로 올렸다. 중첩 후에도 후크가 아래 토트의 림에 갇히지 않게 하는 기능 제약이며, 사진으로 확인한 실제 구멍 높이는 아니다.
- 후크 외형(`hook_tool.obj`): 손목 플레이트 → 테이퍼 기둥 → 납작한 돌기를 단면 로프트로 생성. 사진의 형태를 기능 중심으로 근사한 것이며 출력물의 실측 복제가 아니다.
- 바는 빈 토트 중첩 상태를 나타내는 고정 시각 요소. 실제 가동 조인트나 잠금 장치 기능은 미구현.
- 손잡이/테이퍼/벽 두께/리브/팔레트 개구부 세부 치수는 사진을 참고한 설계 가정. 현재 PoC의 실물 제품과 동일 모델인지 미확인.

## 시뮬레이션과 검증

상세 시각 메쉬는 질량 0, 충돌 비활성이고, 접촉은 숨겨진 단순 형상이 담당한다. 팔레트 포크 구멍의 물리적 통과는 재현하지 않는다. 이번 변경에서 짧은 끝벽을 손잡이 구멍이 뚫린 4장의 판으로 바꿔 돌기가 실제로 구멍을 통과하고 아래 턱에 닿도록 했다. 후크는 `poc_sim/gripper.py`의 사용자 지정 근사 설계로, 공식 Dexmate 그리퍼 CAD가 아니다.

결과는 `docs/validation.md` 참고. `reports/props_detail.png`는 빈 토트 1개와 3개 중첩 외형, `reports/turn_base.png`는 적재 완료 상태, `reports/hook_pick.png`는 실제 후크 삽입 동작에서 렌더링한 장면이다.
